まとめ ＆ 実装詳細

①「次へ」ボタン: .next-btn を background: var(--aws-orange) / color: #000 に変更し、next-pulse アニメーション（2秒周期のボックスシャドウ）を追加。正解・不正解どちらの背景色でも確実に目立つよう配慮。prefers-reduced-motion 対応で動作を止めるメディアクエリも追加済み。


②ランク表示: getRankMessage(score, total, lang) を新設。パーセンテージに応じた日英メッセージと色を返す。結果画面の「ランク」ラベルを「評価」(i18n.ts)に変更し、絵文字ランク名から簡潔な感情メッセージへ切り替え。


③ストリークバッジ: .streak[hidden] { display: block !important; visibility: hidden; } で要素サイズを確保しつつ非表示に。バッジの有無でカードの高さが変わらなくなり、連続正解中も選択肢の位置が安定する。
